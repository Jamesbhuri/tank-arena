# ป้อมเหล็ก 6 ฐาน

เกมรถถัง 3D (กล้องบุคคลที่ 3 หลังรถถัง) บนสนามโอเอซิสกลางทะเลทราย 5–6 คนยิงกันเอง แต่ละคนสร้างฐานเองก่อนเริ่มรบ (ดิน 30 ก้อน หิน 4 ก้อน) แกนทน 5 นัด ไอเทมสุ่มเกิดบนแผนที่ เติมบอทได้

เล่นได้ทันทีในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร เป็นไฟล์เดียว `index.html`

## เล่นออนไลน์กับเพื่อน
1. ใส่ชื่อ แล้วกด **เปิดห้องออนไลน์** จะได้รหัสห้อง (เช่น `TK-4821`) และลิงก์เชิญ
2. เพื่อนเปิดลิงก์ หรือใส่รหัสแล้วกด **เข้าห้อง** เพื่อนจะแทนช่องว่างหรือช่องบอท
3. เจ้าของห้องกด **เริ่มเกม**

เครื่องของเจ้าของห้องเป็นตัวรันเกม (เชื่อมต่อแบบ WebRTC ผ่าน PeerJS) ต้องเปิดแท็บเกมค้างไว้จนจบ ถ้าเพื่อนหลุด บอทจะเล่นแทน

## ปุ่มควบคุม
- ผู้เล่น 1: `W` เดินหน้า, `S` ถอย, `A`/`D` เลี้ยว, `Space` / `F` ยิง
- ผู้เล่น 2: `↑` เดินหน้า, `↓` ถอย, `←`/`→` เลี้ยว, `Enter` / `/` ยิง (เล่น 2 คนบนเครื่องเดียวจอจะแบ่งครึ่ง)
- `C` สลับกล้อง หลังรถ / ภาพรวม, `P` พักเกม
- ช่วงสร้างฐาน: คลิก/ลากเพื่อวาง, คลิกขวาเก็บคืน, `1` ดิน `2` หิน `3` เก็บคืน
