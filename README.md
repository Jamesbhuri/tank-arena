# ป้อมเหล็ก 6 ฐาน

เกมรถถังมุมมองจากด้านบน 5–6 คนยิงกันเอง แต่ละคนสร้างฐานเองก่อนเริ่มรบ (ดิน 30 ก้อน หิน 4 ก้อน) แกนทน 5 นัด ไอเทมสุ่มเกิดบนแผนที่ เติมบอทได้

เล่นได้ทันทีในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร เป็นไฟล์เดียว `index.html`

## ปุ่มควบคุม
- ผู้เล่น 1: `W A S D` เดิน, `Space` / `F` ยิง
- ผู้เล่น 2: ลูกศร เดิน, `Enter` / `/` ยิง
- `C` สลับกล้อง, `P` พักเกม
- ช่วงสร้างฐาน: คลิก/ลากเพื่อวาง, คลิกขวาเก็บคืน, `1` ดิน `2` หิน `3` เก็บคืน
