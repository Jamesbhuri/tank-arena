# ป้อมเหล็ก 6 ฐาน

เกมยิง 3D มุมมองบุคคลที่ 1 บนสนามโอเอซิสกลางทะเลทราย 5–6 คนยิงกันเอง เดินเก็บอาวุธ เกราะ และยาตามแผนที่ ทุกคนมีชีวิตเท่ากัน (ตั้งได้ในห้อง) ตายแล้วเกิดใหม่ ชีวิตหมดคือตกรอบ คนสุดท้ายที่รอดชนะ เติมบอทได้

เล่นได้ทันทีในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร เป็นไฟล์เดียว `index.html`

## เริ่มเล่น
กด **เล่นเลย** ที่หน้าแรก เกมเริ่มกับบอท 5 ตัวทันทีและล็อกเมาส์ให้เลย

## เล่นออนไลน์กับเพื่อน
1. ใส่ชื่อ แล้วกด **เปิดห้องออนไลน์** จะได้รหัสห้อง (เช่น `TK-4821`) และลิงก์เชิญ
2. เพื่อนเปิดลิงก์ หรือใส่รหัสแล้วกด **เข้าห้อง** เพื่อนจะแทนช่องว่างหรือช่องบอท
3. เจ้าของห้องกด **เริ่มเกม**

เครื่องของเจ้าของห้องเป็นตัวรันเกม (เชื่อมต่อแบบ WebRTC ผ่าน PeerJS) ต้องเปิดแท็บเกมค้างไว้จนจบ ถ้าเพื่อนหลุด บอทจะเล่นแทน

## ปุ่มควบคุม
- `W A S D` เดิน, `Shift` วิ่ง, เมาส์หันและเล็ง (คลิกที่จอเพื่อล็อกเมาส์, `Esc` ปล่อย)
- คลิกซ้ายยิง, คลิกขวาเล็ง/ส่องกล้อง, `R` รีโหลด, `F` เก็บของ
- `1` `2` `3` หรือล้อเมาส์ สลับปืน, `4` ผ้าพันแผล, `5` ชุดปฐมพยาบาล
- `-` / `=` ลด/เพิ่มความไวเมาส์ (หรือเลือกในหน้าห้อง), `C` ดูภาพรวม, `P` พักเกม
